# Address of Variable Using Pointer in C

**Author:** M.Likitha

## Description

This program demonstrates how to find the address of a variable and
store that address in a pointer.

## File

address_pointer.c

## Concepts Used

- Address operator `&`
- Pointer declaration
- Pointer initialization
- Dereference operator `*`
- Memory address

## How to Run

gcc address_pointer.c -o address_pointer
./address_pointer

## Sample Output

Value of number = 50
Address of number = 0x7ffd1234
Address stored in pointer = 0x7ffd1234
Value using pointer = 50

The memory address will be different each time the program runs.
